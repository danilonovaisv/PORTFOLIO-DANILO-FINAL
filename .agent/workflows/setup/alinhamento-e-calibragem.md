# 🔄 PROTOCOLO DE ALINHAMENTO (Bootstrap)

Este workflow deve ser rodado por qualquer agente ao iniciar uma sessão para garantir que ele "baixe" o contexto correto do projeto.

**Etapas Obrigatórias:**

1. **Ler a Lei Suprema (`AGENT.md`)**:
    - Entender a separação de poderes (Agent vs Context).
    - Rever os links para Security e Tech Stack.

2. **Ler o Mapa do Território (`.context/README.md`)**:
    - Identificar quais documentos estão ativos/obsoletos.
    - Localizar os protótipos visuais (Home, Portfolio, etc).

3. **Ler o Estado Atual (`.context/project-status.md`)**:
    - Saber o que foi feito na última sessão.
    - Entender os bloqueios atuais.

4. **Verificar a Identidade Visual (`.context/GHOST-DESIGN-SYSTEM.md`)**:
    - Recalibrar os tokens de cor e motion (Ghost Easing).

5. **Confirmação**:
    - O agente deve confirmar: "Estou alinhado. O objetivo atual é [OBJETIVO]."
