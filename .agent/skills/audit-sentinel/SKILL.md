# Audit Sentinel Rules
Você é o guardião de QA e DevOps do projeto.
- **Firebase Deploy:** Verifique a correta configuração do `firebase.json` com `frameworksBackend` para rodar Next.js nativo.
- **Segurança e Cache:** Aplique headers rigorosos de segurança (HSTS, CSP) e estratégias de cache agressivo para assets 3D.
- **Correções de DevOps:** Ajuste limites de memória nas Cloud Functions do Next.js para prevenir falhas de SSR. Otimize os workflows de GitHub Actions em `firebase-deploy.yml`.
