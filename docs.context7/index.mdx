# Danilo Novais Portfolio

Bem-vindo à documentação técnica oficial do **Portfólio Institucional de Danilo Novais** — construído com **Next.js 16 (App Router)**, **React 19**, **React Three Fiber (R3F)**, **Three.js**, **Tailwind CSS v4** e **Supabase**.

Este projeto combina **Creative Coding**, **Motion Editorial** e **Arquitetura Escalável de Alta Performance** sob o paradigma **Ghost Era**:

> _"Você não vê o design. Mas ele vê você."_

---

## ✦ Pilares do Sistema

- **Ghost Design System:** Paleta espectral (`#0048ff`, `#4fe6ff`, `#040013`), tipografia com escala fluida via `clamp()` ('Manrope' e 'PPSupplyMono') e grid responsivo estruturado (`.std-grid`).
- **3D & WebGL Atmosférico:** Cenas 3D isoladas em R3F, shaders GLSL customizados e estrito mandato de 60 FPS com alocação zero em loops `useFrame`.
- **Motion & Coreografia:** Rolagem suave com Lenis, curvas de aceleração Ghost Easing (`[0.22, 1, 0.36, 1]`) e microinterações cirúrgicas.
- **Arquitetura & Realtime:** Server Components no Next.js App Router, estado global via Zustand, Supabase Storage (`site-assets`) e SSR Guardrails para Firebase Hosting e Cloudflare OpenNext.
