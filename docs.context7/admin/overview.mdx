# Visão Geral do Admin

O backoffice em `/admin` permite editar o conteúdo do site sem novo deploy.

## Acesso

As rotas são protegidas por middleware e por Row Level Security. Cada ação sensível confirma `role: 'admin'` em `user_metadata` antes de executar.

## Áreas

- **Assets:** upload e organização de mídia no bucket R2 `portfolio-assets`.
- **Conteúdo:** edição de textos, títulos e links exibidos no frontend.
- **Leads:** leitura dos contatos recebidos pelo formulário.

## Auditoria

Toda escrita no painel gera um registro com autor, horário e valores anteriores e novos. Exclusões de dados relevantes são lógicas, via status, não físicas.

## Realtime

As alterações são persistidas no D1 e a rota afetada é revalidada, aparecendo no site sem refresh.
