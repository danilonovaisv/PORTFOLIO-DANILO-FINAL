# Configuração do Ambiente

## Pré-requisitos

- Node.js 20 ou superior.
- pnpm (gerenciador oficial do projeto).
- Acesso ao projeto Cloudflare (D1 e R2), ao projeto Supabase (autenticação do `/admin`) e ao Firebase Hosting.

## Instalação

```bash
pnpm install
pnpm run dev
```

## Variáveis de ambiente

As chaves ficam em `.env.local` e nunca são commitadas. As variáveis devem ser validadas em runtime antes do build.

O conteúdo é lido do Cloudflare D1 pelo binding `DB`, configurado no `wrangler.toml` (`database_name = "portfolio-db"`). A mídia é servida pelo Cloudflare R2, que exige `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID` e `R2_SECRET_ACCESS_KEY` no servidor, além de `R2_BUCKET_NAME` (padrão `portfolio-assets`) e `NEXT_PUBLIC_R2_PUBLIC_URL` para o CDN público.

## Comandos

```bash
pnpm run dev          # servidor local
pnpm run build-check  # lint + typecheck
pnpm run build        # build de produção
pnpm test             # testes unitários
pnpm test:e2e         # testes E2E
pnpm run deploy       # deploy no Firebase Hosting
```

## Verificações antes do deploy

- `engines.node` idêntico entre a raiz e `functions/`.
- Pasta `.next` presente e com o manifesto de servidor gerado.
- `firebase-admin` e `firebase-functions` como dependências de produção.
