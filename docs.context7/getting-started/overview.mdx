# Visão Geral

O **Danilo Novais Portfolio** é um portfólio institucional construído sob o paradigma **Ghost Era**: Creative Coding, Motion Editorial e arquitetura escalável de alta performance.

O sistema é dividido em três camadas conceituais.

1. **Camada Visual:** o Ghost Design System define paleta, tipografia com escala fluida via `clamp()` e o grid responsivo `.std-grid`.
2. **Camada de Motion:** cenas 3D isoladas em R3F, shaders GLSL customizados e coreografia de interface com Lenis e Ghost Easing (`[0.22, 1, 0.36, 1]`).
3. **Camada de Dados:** Server Components no Next.js App Router, estado global via Zustand, Supabase Storage (`site-assets`) e SSR Guardrails para Firebase Hosting.

- **Getting Started:** visão geral, stack tecnológica e configuração de ambiente.

- **Admin & Backoffice:** painel administrativo, assets e conteúdo dinâmico.
- **DevOps & Deployment:** procedimentos de deploy, SSR guardrails e gates de verificação.
