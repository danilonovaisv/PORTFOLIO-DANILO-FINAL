# Fonts

Primary: **Manrope** Variable (wght 200–800) — self-hosted. Place `Manrope-VariableFont_wght.woff2` in this folder.

Mono: **PPSupplyMono** — loaded from a CDN (`https://assets.codepen.io/7558/PPSupplyMono-Variable.woff2`) in the source repo. Included via `@font-face` in `colors_and_type.css`.

> **Substitution note:** Manrope Variable is available on Google Fonts and bunny.net. If you cannot host the woff2 locally, fall back to the Google Fonts CDN:
>
> `<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap" rel="stylesheet">`
