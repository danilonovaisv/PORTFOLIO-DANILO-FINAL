# 🛠️ AGENT CUSTOMIZATION CONFIG

Este arquivo ativa e configura o uso sistemático das regras e workflows do projeto.

## 📁 Paths Configurados

### Rules (Regras)

Todas as regras de comportamento, estilo de código e design system estão centralizadas em:
`./agent/rules/*.md`

### Workflows (Fluxos de Trabalho)

Todos os workflows estruturados para automação e auditoria estão localizados em:
`./agent/workflows/*.md`

## 🚀 Ativação

Ao iniciar qualquer tarefa, o agente deve carregar o arquivo `.agentrules` na raiz como o mapa principal de navegação e cumprir as diretrizes contidas em cada arquivo registrado.
