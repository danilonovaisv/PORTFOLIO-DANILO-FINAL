# Workflow: Project Case Improvement

Trigger: improve `/projects/[slug]`.
Goal: stronger editorial presentation using reusable content blocks.

Agents:
- Portfolio Experience Specialist
- Quality Verification Specialist

Steps:
1. Trace slug/data/renderer.
2. Inventory current content blocks.
3. Select representative sparse and rich projects.
4. Produce delta spec for added/modified/removed block behavior.
5. Implement responsive editorial hierarchy.
6. Verify direct URL, refresh, 404/missing data, and internal navigation.
7. Validate accessibility basics and media behavior.
8. Run visual and automated regression checks.

Completion Criteria:
Representative cases render coherently across mobile/tablet/desktop and existing content remains compatible.
