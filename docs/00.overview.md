# 00. Overview

## Contexto
Este pacote documenta o ajuste da seção `06-O-QUE-ME-MOVE` da rota `/sobre` do projeto `portfoliodanilo.com`.

A base de verdade usada nesta documentação foi:
- `MASTER-KNOWLEDGE-MAP.pdf`
- `06-O-QUE-ME-MOVE.md`
- `Antigravity Documentation & Prompt Engine — Workspace Template.md`
- `prompt-structure.md`
- bases auxiliares de skills e Firebase

## Escopo
O pacote cobre:
1. requisitos da seção
2. arquitetura de DOM Motion + Ghost 3D
3. ADR da decisão arquitetural
4. plano de implementação
5. task list por fases
6. prompt final para o Agent Manager
7. runbook de validação e release

## Premissas
- Motion no DOM para background, overlay, textos, header e manifesto.
- React Three Fiber + drei + three.js apenas no `GhostScene`.
- `getAssetUrl()` de `@/lib/utils` é a fonte canônica para resolução de assets.
- Tailwind deve preservar `@import "tailwindcss" source(none)` com `@source` explícitos.
- A seção deve respeitar os tokens Ghost e a filosofia de motion do projeto.
- O Ghost permanece acima do manifesto no clímax.
