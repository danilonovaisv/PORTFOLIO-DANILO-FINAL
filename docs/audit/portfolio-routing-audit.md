## 4. Divergências Estruturais e de Comportamento Identificadas

   - [`src/lib/portfolio/project-mappers.ts`](file:///Users/danilonovais/PORTFOLIO-DANILO-FINAL/src/lib/portfolio/project-mappers.ts) tenta ler `project.destination` e `project.case_body`.

   - [`src/components/home/featured-projects/FeaturedProjectsRealtime.tsx`](file:///Users/danilonovais/PORTFOLIO-DANILO-FINAL/src/components/home/featured-projects/FeaturedProjectsRealtime.tsx) e [`src/app/portfolio/PortfolioClient.tsx`](file:///Users/danilonovais/PORTFOLIO-DANILO-FINAL/src/app/portfolio/PortfolioClient.tsx) executam `supabase.from('public_projects_view')` no cliente.    - O 8º projeto da Home no D1 usa `slug = zevi-identidade-visual-branding-cafe-premium`, mas [`FALLBACK_LANDING_PAGES`](file:///Users/danilonovais/PORTFOLIO-DANILO-FINAL/src/lib/projects/landing-page-fallback.ts#L16-L18) usa `slug: 'zevi'`. Qualquer acesso a `/projects/zevi` vs `/projects/zevi-identidade-visual-branding-cafe-premium` precisa de resolução consistente (ou alias controlado via D1 / redirect).
4. **Remoção segura de gerador genérico:**
   - Em [`src/app/projects/[slug]/page.tsx`](file:///Users/danilonovais/PORTFOLIO-DANILO-FINAL/src/app/projects/[slug]/page.tsx), o fallback genérico (`"Projeto do Portfólio Ghost Era"`) viola a política **Zero Placeholder** e esconde falhas de banco.
