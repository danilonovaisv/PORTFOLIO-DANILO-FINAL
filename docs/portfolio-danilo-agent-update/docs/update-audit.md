# UPDATE / AUDIT Decisions

## ADD
- admin-reliability-specialist
- portfolio-experience-specialist
- quality-verification-specialist
- focused skills and workflows in this package

## UPDATE / MERGE
- Existing project orchestrators -> one routing contract
- Existing frontend developer/specialist variants -> portfolio-experience-specialist
- Existing debugger/debugging variants -> route project-specific debugging through Admin Reliability or Portfolio Experience based on domain
- Existing test/reviewer capabilities -> quality-verification-specialist

## KEEP
- database-sentinel when it is already project-specific and least-privilege
- visual/shader specialist if it owns current Three.js/shader behavior
- security rules, performance rules, accessibility rules that are valid and referenced
- IDE adapters that are actively used

## REMOVE
Only after comparison proves the file is fully superseded:
- duplicate aliases with no unique responsibilities;
- broken references to nonexistent agents/skills;
- stale generated catalogs not consumed by the active IDE;
- redundant workflows fully covered by an updated workflow.

## MERGE RULE
Preserve unique project-specific requirements from the older file. Do not replace a specialized capability with a shorter generic prompt merely to reduce file count.
