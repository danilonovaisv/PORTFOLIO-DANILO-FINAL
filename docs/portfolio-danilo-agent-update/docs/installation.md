# Installation

This package is a universal specification, not a blind-copy payload.

1. Open PORTFOLIO-DANILO-FINAL in the actual Agent IDE.
2. Run the supplied `PROMPT-FOR-AGENT-IDE.md`.
3. Let the IDE inspect existing `.agents`, `.agent_config`, `.claude`, `.codex`, `.qwen`, `AGENTS.md`, rules, skills, commands and manifests.
4. Confirm its KEEP/UPDATE/REMOVE/ADD/MERGE mapping.
5. Apply non-destructive additions and merges.
6. Update internal references and routing.
7. Validate IDE-specific syntax and capabilities.
8. Run project-supported checks.
9. Review the final change report before deleting obsolete files.

Do not delete duplicate-looking files solely by filename; compare responsibilities and active references first.
