## 1. Resumo das Modificações (@data-sentinel & @audit-sentinel)
- **Firebase Limits**: Memória de Cloud Functions SSR (Next.js) aumentada de 1GiB para 2GiB no `firebase.json` para suportar processamento intensivo de WebGL/Hydration.

- **Supabase RLS**: Atualizado diretamente no banco (via SQL MCP) garantindo total isolamento:
  - Anônimos: `SELECT` (Apenas Leitura)
  - Admin/Owner: `INSERT`, `UPDATE`, `DELETE` (Escrita restrita)
