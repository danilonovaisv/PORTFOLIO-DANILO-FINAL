# 🛰️ Guia de Operações do AntiGravity IDE
**Versão**: 4.1.22 (Estável para Marketing e NPM)

**Idioma**: Vietnamita (Interface) - Inglês (Técnico)

Bem-vindo ao sistema AntiGravity IDE atualizado. Ele não é mais apenas uma ferramenta de programação comum, mas sim uma **Sala de Guerra de IA** com conhecimento completo de negócios e uma linha de produção profissional.

---

## 🛠️ 1. Pré-requisitos
Para garantir que o sistema opere com 100% de capacidade, você deve instalar:

- **Node.js**: Para executar comandos de instalação e gerenciamento de pacotes (Requer versão 18 ou superior).

- **Python 3.x**: (**Recomendado**) Para habilitar as Skills e executar scripts automatizados, como Scanners, Evaluators e Data Science.

## 🚀 2. Início Rápido

Para instalar ou atualizar o sistema para o nível Global, use os seguintes comandos:

- **Nova instalação**: `npx antigravity-ide [nome-do-projeto]`
- **Inicialização rápida**: `npx antigravity-ide --skip-prompts` (Usa a configuração padrão).

- **Atualização de recursos**: `npx antigravity-ide` (Executar o comando na pasta do projeto acionará a atualização automaticamente).

---

## 🏎️ 2. Modos do Motor

O AntiGravity oferece dois modos de operação flexíveis, dependendo das necessidades do projeto:

- **Modo Padrão (Node.js)**:

- *Objetivo*: Leve, rápido e sem necessidade de configuração.

- *Uso*: Adequado para projetos Web, de portfólio e SaaS de pequeno e médio porte.

- **Modo Avançado (Python)**:

- *Objetivo*: IA complexa, de alta segurança e aprofundada.

- *Uso*: Adequado para projetos corporativos, Big Data e Pentest.

--- ## 🛡️ 5. Preservando Conteúdo Personalizado (Marcadores)
Ao executar o comando `update`, o AntiGravity IDE sincronizará os arquivos do sistema, mas ainda **respeitará** o que você escreveu.

Para impedir que a IA sobrescreva seu código crítico, use o seguinte marcador:
```javascript
// [CUSTOM_START]

// Escreva seu próprio código ou anotações aqui...

// O sistema nunca alterará esta área durante as atualizações.

const myPrivateApiKey = "xyz";

// [CUSTOM_END]
```
